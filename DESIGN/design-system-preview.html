Design rules for Bright

Enforced from PRD §6 + AD-01/02/09/11

  • Min 48px buttons, 16px+ text, high contrast for sunlight.
  • Voice first, never voice-only: transcript + edit + browse always visible.
  • One payment screen: itemized + delivery + total + MoMo prompt.
  • Landmark field on every address: e.g. “Behind Kejetia Market, blue kiosk”.
  • WhatsApp/SMS mirror only key states to save cost.
